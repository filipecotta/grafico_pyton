# Gráficos com Python

Um script por gráfico. Coloque os CSVs na mesma pasta dos scripts.

| Script | CSV | Gráfico |
|---|---|---|
| 01_heatmap.py | dados_heatmap.csv | Mapa de calor |
| 02_linhas.py | dados_linhas.csv | Linhas |
| 03_pizza.py | dados_pizza.csv | Pizza |
| 04_regressao.py | dados_regressao.csv | Regressão linear |
| 05_barras.py | dados_barras.csv | Barras agrupadas |
| 06_boxplot.py | dados_boxplot.csv | Boxplot |
| 07_dispersao.py | dados_dispersao.csv | Dispersão |
| 08_distribuicao.py | dados_distribuicao.csv | Histograma |
| 09_frequencia.py | dados_frequencia.csv | Frequência |

## Como executar
```
pip install -r requirements.txt
python 01_heatmap.py
```
